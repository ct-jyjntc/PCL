# PCL 联机绿色版

这是第三方基于 PCL 官方正式版制作的功能补丁绿色版，与 PCL 官方无关。
PCL 原作者：龙腾猫跃；赞助：https://meloong.com/afd/a/LTCat 。

## 运行

解压整个文件夹，双击 `Plain Craft Launcher 2.exe`。不要只复制 EXE，旁边必须保留：

- `PCL.Link.UI.dll`
- `Link\PCL.Link.exe`
- `Link\kernel\ETLanCore.exe`
- `Link\kernel\wintun.dll`

首次启动会在当前目录创建 `.minecraft`、`PCL` 等正常启动器目录。绿色包本身不附带：

- Minecraft 游戏、版本或存档
- PCL 设置、登录缓存
- 组网账号、token 或密码

## 联机

1. 打开 PCL 并登录 Minecraft 正版或填写离线玩家名。
2. 启动页右侧会自动准备组网账号，不需要填写组网平台密码。
3. 点击「创建网络」，把 6 位网络 ID 发给朋友；朋友输入 ID 后点击「加入」。
4. 房主在 Minecraft Java 世界中选择「对局域网开放」。
5. 朋友打开「多人游戏」，等待局域网世界出现并连接。

第一次创建或加入网络时，Windows 会请求管理员权限，这是创建虚拟网卡所需。
PCL 本身仍以普通权限运行。组网账号和 token 使用当前 Windows 用户的 DPAPI 加密，
保存在 `%LOCALAPPDATA%\PCL\Link\account.json`，不会写入本绿色包的游戏目录。

## 兼容性

- 需要 Windows 10/11 x64。
- 联机需要双方都使用包含本联机模块的版本；普通 Alien Link 可通过虚拟 IP 连接，但不会交换自动发现公告。
- 未发现世界时，可以尝试用房主显示的虚拟 IP 与 Minecraft 局域网端口直接连接。
- Minecraft 版本、模组、局域网服务端验证和防火墙设置仍需双方兼容。
- 组网内核及驱动的公开再分发授权仍需由发布者核实，详见 `Link\kernel\PROVENANCE.md`。

本绿色版基于官方 `2.99.0.1`，保留正式版下载/整合包恢复和现有外观。第三方补丁工具与本绿色版分开提供。

## fix1

- 修复成员因“直连对端为 0”统计而周期性消失。
- 修复转发公告被再次捕获，导致局域网世界和标签重复增长。
- 同一世界固定使用同一个本机代理端口；短暂断线或公告刷新不再生成新端口。
- 已离开的成员立即停止公告；明确重连后恢复原端口。
- 若仍看到旧的重复世界，退出到游戏主菜单后再进入「多人游戏」刷新列表。
