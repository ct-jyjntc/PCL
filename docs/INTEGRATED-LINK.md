# PCL 内置联机修改版

这是第三方基于 Plain Craft Launcher 独立修改的版本，不是 PCL 官方发布物。
PCL 原作者：龙腾猫跃；赞助：https://meloong.com/afd/a/LTCat 。

## 使用

启动 `Plain Craft Launcher 2.exe`，联机卡片位于启动页右侧。不要只复制 EXE；保留旁边的 `Link` 文件夹及 DLL。

1. 打开启动器时会自动创建并登录带唯一后缀的组网账号，不需要填写组网账号或密码。
2. 登录 Minecraft（正版或离线）后，联机按钮启用，设备名自动同步为游戏玩家名。
3. 房主创建网络，把 6 位网络 ID 发给朋友；朋友输入 ID 加入。
4. 在 Minecraft Java 单人世界中选择「对局域网开放」。
5. 朋友打开「多人游戏」，等待局域网世界出现，直接点击连接。

双方需要支持自动发现的新版 PCL。通用组网仍能与独立 Alien Link 互通，但其旧版不会交换 Minecraft 世界公告。
如果没有显示，确认房主已开放局域网、Java 防火墙规则允许入站，然后使用房主虚拟 IP 与游戏端口直接连接。
版本、模组、模组加载器与登录策略仍需兼容。这里只处理网络与发现，不绕过 Minecraft 服务端验证。

## 权限与退出

PCL 保持普通用户权限。第一次创建或加入网络时，仅联机后台请求管理员授权，用于 Wintun 网卡与内核防火墙规则。
当前版本需要用同一个 Windows 账号完成提权；标准账号输入另一位管理员的凭据时，不共享该管理员的组网后台或 DPAPI 账号文件。
取消授权不会影响启动器其他功能。自动账号密码和 token 都只以当前 Windows 用户的 DPAPI 密文保存于
`%LOCALAPPDATA%\PCL\Link\account.json`；密码不会明文落盘，也不会读取游戏登录令牌。

切换页面不退出组网。关闭 PCL 时可选择退出联机、保持联机或取消关闭。
保持后后台继续运行，再次进入联机页会连接现有后台；退出会清理本模块持有的内核和游戏端口转发。
异常关闭启动器时，后台在约 30 秒失去心跳后退出，除非此前明确选择保持联机。
不按网卡描述批量删除适配器，不干扰独立 Alien Link 的适配器。

## 自动发现原理

Minecraft Java 使用 `224.0.2.60:4445` 公告局域网世界，单纯虚拟 IP 互通不保证组播透传。
本模块捕获本机公告，仅向同一虚拟 /24 网络内的已知成员用 UDP `45889` 交换世界名称和端口。
接收方创建仅监听 `127.0.0.1` 的 TCP 转发，并在回环网段向 Minecraft 发送公告。
使用回环广播而非单播，避免多个共享 `4445` 的游戏/监听器相互抢包。
不会转发物理局域网邻居的世界，不接受陌生设备指定的转发目标，成员离开或公告过期会关闭代理。

## 构建

需要 .NET SDK 10、Visual Studio Build Tools 的 .NET desktop build tools，以及 Git。

```powershell
./tools/Build-Link.ps1
```

脚本初始化已固定提交的 MeloongCore、构建 WPF 主程序、运行测试、发布自带运行时的 x64 联机后台并打包到 `dist`。
目标为 Windows 10/11 x64，不需要另装 .NET 10；PCL 主程序仍依赖 .NET Framework 4.8。

## 验证范围

自动测试覆盖公告解析、恶意/超长输入拒绝、DPAPI、自动账号首次注册/免登录/过期续登/断网防重复注册、
状态快照、双向 TCP 代理、多个局域网监听器、陌生成员拒绝、成员退出清理，以及命名管道状态与退出协议。
构建测试还检查恢复后的下载加载器、整合包分派、资源安装入口和下载限制常量。
这些是本机协议测试，不等价于两台真实电脑经过互联网、中继和真实 Minecraft 世界的完整验证；发布前仍应做双机测试。
