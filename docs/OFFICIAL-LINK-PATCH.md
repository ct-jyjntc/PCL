# PCL 官方正式版功能补丁

这是第三方功能补丁，与 PCL 官方无关。PCL 原作者为龙腾猫跃，赞助链接：https://meloong.com/afd/a/LTCat 。
本工具不是源码重编译版：它保留用户提供的官方 EXE，一次完成下载/整合包恢复和启动页联机接入。

## 支持范围

- 当前仅支持经过结构指纹验证的官方 `2.99.0.1`。
- 按 EXE 实际版本识别，不按文件夹名称；已安装指定下载/整合包补丁的该版本也可使用。
- 其他版本、接入点指纹变化、数字签名、来源不符都会拒绝修改。
- 不叠加重复补丁；升级联机模块前先用工具还原，再应用新版。

## 使用

1. 打开 `PCL.Link.Patcher.exe`，选择你自己的官方 PCL EXE。
2. 勾选需要的功能：「恢复下载与整合包」「启动页联机」「防止自动更新覆盖补丁」。默认生成程序副本，不覆盖原 EXE。
3. 点击「生成补丁副本」。如果明确要改原 EXE，可勾选直接修改；工具仍先备份。
4. 先退出其他 PCL 窗口，再启动生成的 PCL。正式版共用单例机制，否则可能只是唤起旧窗口。
5. 默认空白主页的右侧直接显示联机卡片；自定义主页内容不会被覆盖，卡片独立放在其上方。顶部不再新增「联机」按钮。
6. 保留 EXE 旁的 `PCL.Link.UI.dll` 与 `Link` 文件夹，不要只复制 EXE。

工具不迁移游戏、存档、登录缓存或配置。生成的副本仍使用官方 `PCL` 配置分支，但目录内游戏文件由用户自行处理。
正式版原有的登录、主题、下载鉴权、资源和已安装下载补丁保留。补丁不会读取、导出、复制或重新配置官方密钥。

## 自动账号与联机

用户不需要单独登录组网平台。首次打开会自动创建一个带唯一后缀的组网账号，密码由随机字节生成，
仅在当前 Windows 用户下用 DPAPI 加密保存；后续启动直接复用已验证的 token，过期时使用同一账号自动续登。
如果注册请求中断，会先尝试用同一账号密码登录，不会每次启动重新注册。
同一 Windows 用户的多个补丁副本共享一个联机后台，避免并发注册账号或重复创建虚拟适配器。

未登录 Minecraft（正版或离线）时不会启用创建/加入网络。此时后台仍可完成组网账号准备，但联机按钮保持禁用。
游戏账号登录成功或填写有效离线名后，设备显示名自动同步为游戏玩家名。它只读取 PCL 已登录后的玩家显示名，
不读取、保存或转发微软密码、OAuth token 或游戏账号令牌。

创建网络后把 6 位网络 ID 发给朋友。房主在 Minecraft Java 世界中选择「对局域网开放」。
双方使用支持自动发现的联机模块时，公告会经虚拟网络交换，并通过本机 TCP 代理出现在多人游戏列表中。
不保证虚拟网卡直接透传 Minecraft 组播；发现模块为此补齐了公告转发。不能发现时使用虚拟 IP:游戏端口兜底。
版本、模组及服务端登录策略仍需兼容，模块不绕过服务端验证。

PCL 本身不提权，仅联机后台按需请求管理员权限。当前需使用同一 Windows 账号完成提权。
组网 token 和自动账号密码以 DPAPI 加密，保存在 `%LOCALAPPDATA%\PCL\Link`；不会写入游戏目录或存档。
关闭 PCL 可选择退出组网、保持组网或取消关闭。

## 校验与还原

写入前检查版本、方法指纹、DLL/内核 SHA-256；副本写入后再次读取验证。
所有非联机方法及原有嵌入资源必须保持一致，官方配置分支和程序集身份不变。
备份在目标程序目录 `Link\Backups\<原始SHA256>.exe`，不会覆盖下载补丁原有的 `.bak`。
选择补丁后的 EXE，再点击「还原所选启动器」，将恢复打联机补丁前的精确文件。
若 EXE 在打补丁后又被其他工具改变，自动还原会停止，避免覆盖后续修改。
还原不删除联机文件、账号、游戏或存档；也不强行结束用户明确保持的后台连接。

官方更新会覆盖接入点。勾选「防止自动更新覆盖补丁」会阻止静默自动更新，并把更新方式默认设为不自动更新；
这不会强行禁用用户手动检查更新。更新 PCL 后需重新运行工具并检查适配，不能盲目应用到未适配版本。

## 世界重复与成员闪退修复

- 内核的直连对端数量只是连接统计，不再据此清空网络成员；中继期间成员保持显示。
- 扫描发现的设备采用 60 秒保留期，明确的成员离开事件仍立即生效。
- 发现模块不再接收自己或其他旧后台转发的 `PCL 联机` 公告，防止公告循环和标签不断叠加。
- 同一虚拟 IP 与游戏端口在整个网络会话中保留固定本机代理端口；公告过期或成员重连不会重新分配端口。
- 短暂缺失的成员快照有 30 秒容错，明确离开则停止公告；界面按 IP 更新原有设备行，不再每次清空重绘。

升级时先关闭旧 PCL 并选择退出联机，不要保持旧后台。若 Minecraft 列表已有历史重复条目，
返回游戏主菜单再进入「多人游戏」可清空旧缓存。新版若检测到旧后台，会禁用创建/加入并给出重启提示。

## 开发

```powershell
./tools/Build-OfficialPatch.ps1 -OfficialExe 'C:\path\Plain Craft Launcher 2.exe' -MakeSample
```

需要 .NET SDK 10 与 Visual Studio 的 .NET desktop build tools。界面 DLL 面向 .NET Framework 4.8，组网后台自带 .NET 运行时。
CLI：`inspect EXE [--download] [--no-link] [--protect-updates]`、
`patch INPUT OUTPUT PAYLOAD [选项]`、`verify ORIGINAL PATCHED`、`restore EXE`。
构建器用提供的已知版本生成接入点适配表；公开发布前需验证目标版本，不能把新指纹当成自动兼容保证。

本机测试覆盖写入后校验、非联机方法和资源保留、已有下载补丁保留、重复处理、精确回滚、冲突文件保护及未知版本拒绝。
原生页另以隔离注册表的 .NET Framework 进程做构造、控件命名绑定和渲染检查，不运行官方启动、登录、更新或游戏目录扫描。
这些不等同于真实双机 Minecraft 联机验证。测试版尚无代码签名；只使用可信来源的补丁工具。
内核来源与尚需核实的公开再分发授权见 `Payload/Link/kernel/PROVENANCE.md`。本地构建不代表获得了公开分发授权。
Mono.Cecil 使用 MIT 许可；本项目 UI 参考及 PCL 相关使用要求见同包 `LICENCE`。
